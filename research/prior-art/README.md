# prior-art/ — Bol Processor (bp4) porting study

These documents come from the former `Algorithmic composer` study (BP-2.9.8 source +
a bp4 porting plan). They are **prior art for the arranger core**: sound-object placement
semantics (pivot / cover / gap / relocation, pre/post-roll), rational integer-ratio time
with LCM-aware quantization, and auto-arrange. `RESEARCH.md` cites them as such.

- `bp4-overview-document.md` — what Bol Processor is and how its polymetric structure /
  generative grammar model works.
- `bp4-porting-plan.md` — the plan to port these semantics into the arranger.

The archived `BP-2.9.8-source.tgz` was dropped (source is public; not needed here).
